# Аренд: устойчивые циклы поз 28–55

| Кадры | Итоговое действие |
|---|---|
| 28–31 | Двигается только страница внутри одной неподвижной книги |
| 32–35 | Одна фронтальная стойка с небольшим симметричным дыханием |
| 36–39 | Дыхание спиной; голова, таз и ноги не перемещаются |
| 40–43 | Одно неподвижное кресло, слегка двигаются только руки на коленях |
| 44–47 | Одна чашка: перед грудью, выше, у рта, опускает |
| 48–51 | Держит чашку обеими руками, меняет хват; 51 больше не пустая |
| 52–55 | Один профиль вправо и небольшие жесты ближней рукой |

Положение головы и обувь закреплены внутри каждой группы. Основания поз
сохранены в `art/arend/pose_bases.png`, чашка — в `art/arend/cup.png`,
управление слоями — в `art/arend/compose_pose_cycles.py`. Правки 0–27
сохраняются побайтно. Ходьба вправо и влево не менялась.

Все пять описаний анимаций обновлены синхронно в `scripts/build_arend.py`
и `assets/Code/arend.json`: чтение использует 28–31, спокойная стойка 32–35,
кресло 40–43 с входом/выходом 32, чай 44–47, птицы 52. Так персонаж больше
не достаёт книгу посреди спокойной стойки и не появляется с чашкой перед
тем, как сесть в кресло.

Экспортёр обновляет 19 отдельных GIF и два обзора, а также галерею
`output/ArendSprites-2026-10-27/animations/index.html`. У изображений в
галерее есть версия по хешу файла, чтобы после перезагрузки не оставались
старые GIF из кеша. Для просмотра дыхания в отдельных GIF замедлены фазы.

Установщик заменяет два PNG и `assets/Code/arend.json`. До изменений
исходный и установленный JSON совпадали; проверка базового SHA-256
останавливает установку, если чужие изменения появились позже. Все три
оригинала сохраняются перед заменой. В JSON меняются только пять описаний
анимаций; события и остальное содержимое не меняются.

Установлены оба PNG и JSON последовательностей. SHA-256 всех трёх файлов
совпадает с проверенной сборкой. Все 13 групп проверок пройдены, затем
отдельно пройден `validate_arend_behaviour.py` на установленном паке.
Визуальная проверка выполнена на GIF из готовых PNG; игровая сцена не запускалась.
