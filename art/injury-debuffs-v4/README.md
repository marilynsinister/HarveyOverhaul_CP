# Дебаффы травм — отдельные символы

Новая перерисовка использует собственный крупный символ для каждого типа
травмы. Разлом кости, шина на лодыжке, порез лезвием, огонь на ладони,
разорванный мышечный пучок, осколки металла, микроб и хирургические швы
отличаются основным силуэтом и цветом.

Исходник игровых рисунков — `../../scripts/injury_debuff_icons.py`. Каждый
рисунок записан на сетке 16×16. Уменьшение, сглаживание и обработка большого
изображения при создании PNG не используются. Тёмный контур непрозрачный,
прозрачность бинарная. Увеличение применяется только в превью.

[`concept.png`](concept.png) — художественный ориентир, созданный встроенным
`image_gen`; полный промпт — [`concept-prompt.txt`](concept-prompt.txt).
Игровые изображения перерисованы отдельно в нативном размере, а не уменьшены
из этого эскиза.

`preview.png` показывает игровые иконки в 16px, ×3 и ×6 на двух фонах.
`comparison.png` сравнивает новую версию с предыдущими установленными PNG.
`exports/` содержит шестнадцать основных значков отдельными PNG 16×16.
`before/` хранит предыдущие листы и код до этой перерисовки.

Основной лист иконок имеет прежний размер 256×176. Связанный старый лист
травм имеет размер 64×48. Все индексы Content Patcher сохранены.
Главный генератор `draw_native_icons.py --install` подключает эти рисунки
после общих анатомических значков, поэтому старые рисунки не перезаписывают
новые дебаффы при повторном запуске.
