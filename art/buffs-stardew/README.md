# Иконки баффов и дебаффов Stardew Valley

**Обновление 26 октября 2026:** рабочие листы заменены нативными рисунками
16×16 с общим тёмным контуром. Текущая версия — [native-16](../native-16/README.md).
Экспортёр вызывает новый пиксельный исходник. Ниже — история старой версии.

Перерисованы встроенным `image_gen` 20 октября 2026 года. Все промпты —
в `prompts.json`, исходные генерации — в `generated/`, исходные спрайты
перед заменой — в `originals/`.

Все ячейки — 16×16, с бинарной прозрачностью и отступом от соседних ячеек.
Индексы 0–163 сохранены. «Ясная голова» получила отдельную иконку 164,
«Запах дыма» — 165: раньше они использовали щит иммунитета и грозовую тучу.
Десять оставшихся ячеек основного листа прозрачны.

Для фаз травм сохранены разные рисунки: острая боль и красные акценты,
перевязка/лечение и янтарные акценты, восстановление и зелёные листья.
Лечение стресса узнаётся по зелёному плюсу рядом с символом состояния.
Основной лист, справочник и дополнительные травмы проверены на совпадения
иконок после уменьшения. Не найдено одинаковых ячеек внутри каждого листа.

`export-buffs.ps1` выполняет техническую подготовку: выделение ячеек из
генераций, уменьшение без сглаживания, приведение к общей палитре,
упаковку в исходные игровые размеры и проверку прозрачности/индексов.
Ключ `-Install` копирует выбранные PNG в исходники модов в рабочей папке.
Для повторной обработки нужен PowerShell 7 в Windows.

Генераторы `generate_buff_icons.py` и `generate_medical_item_sprites.py`
теперь сохраняют подготовленные рисунки из `exports/` при повторной сборке.
Основной генератор проверяет состав эффектов и не меняет отдельные иконки
предметов Аренда или медицинских предметов.

Установка в игру: при закрытой игре запустите `install-game-assets.ps1`.
При другом расположении модов передайте `-GameModsRoot` с путём к каталогу,
в котором находятся модули набора Harvey Overhaul. Их папки определяются
по `UniqueID` в манифестах: стресс-модуль в исходниках называется
`HarveyStressMeter`, а в этой установленной игре — `HarveyOverhaulStress`.
Скрипт сохраняет прежние файлы в `game-before/`, устанавливает PNG и карту,
а в двух JSON меняет только индексы новых иконок. Он проверяет, что
остальные поля JSON не изменились.

Для отката верните файлы из `originals/` в исходники и замените либо
уберите соответствующие экспорты; для отката установленной игры верните
файлы из `game-before/` в каталог модов с сохранением структуры папок.

Превью: `preview.png` — весь набор; `preview-treatment.png` — лечение и
фазы травм; `preview-debuffs.png` — травмы, стресс и осложнения.
В игре изображения пока не просматривались; выполнена проверка PNG и
ссылок Content Patcher.
