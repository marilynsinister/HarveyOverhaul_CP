# Разборчивые значки при ванильном HUD

21 октября 2026. Исправление после версии с увеличением значков.

Из Core удалены Harmony-патч `BuffsDisplay.resetIcons`, собственная сетка и
параметр `LargeBuffIcons`. Игра сама задаёт размеры, координаты, переносы,
анимацию и области наведения всех эффектов. Старое значение
`LargeBuffIcons` в пользовательском конфиге больше не влияет на интерфейс.

Встроенным image_gen созданы 16 упрощённых силуэтов для наиболее частых
состояний, включая эффекты на присланном скриншоте. Исходная генерация
сохранена в `generated/common-statuses.png`, промпт — в `prompt.txt`.

`export_readable_icons.py` механически выделяет 16 ячеек из генерации,
уменьшает ближайшим соседом, делает прозрачность бинарной и размещает
результат в прежних ячейках 16×16. Индексы всех 166 эффектов сохранены;
остальные 150 рисунков не менялись. Шесть соответствующих значков в
справочнике синхронизированы с HUD.

Экспорт проверяет размеры, отступы, прозрачность, уникальность замен,
неизменность остальных ячеек и пустые резервные ячейки. Порядок и список
замен — в `export-report.json`. Сравнение натуральных 16px и увеличенных
для просмотра спрайтов — в `preview.png`.

Запуск из корня рабочей папки:

```powershell
python 'HarveyOverhaul [CP]/art/buffs-readable/export_readable_icons.py'
```

Канонические экспорты по-прежнему лежат в `../buffs-stardew/exports`,
поэтому обычная генерация мода сохраняет новую графику. Повторный запуск
старого `../buffs-stardew/export-buffs.ps1` восстанавливает старую графику;
после него необходимо снова запустить `export_readable_icons.py`.

Core собирается с отключённой автоматической установкой; пакет и резервная
копия установленной версии готовятся отдельно в `output`. Подтверждена
сборка и 743 проверки; визуальный просмотр в запущенной игре не выполнялся.
