# Аптекарский сад: нативный пиксель-арт

28 октября 2026. Все четыре растения, стадии роста, урожай и семена
перерисованы сразу в игровых размерах. Большие изображения не уменьшаются.
Текущая версия `native-v4` следует присланному примеру Wildflour: компактные
пышные кустики, округлые плоды, тёплые маленькие блики, зелёная листва
с цветными тенями. Внутренние края имеют оттенок материала, наружный контур
остаётся тёмным. Рисунки заново записаны пиксельными матрицами.

- Кадр культуры — **16×32**, иконка предмета — **16×16**.
- Контур — непрозрачный тёмно-зелёный `#263e31`, толщиной в один пиксель.
- Каждый лист использует менее 64 цветов и бинарную прозрачность; сглаживания нет.
- Исходник — `../../scripts/native_herbal_garden.py`: пиксельные матрицы
  цветов, листьев и ягод, координаты стеблей. Один символ — один игровой пиксель.
- Урожай нарисован отдельно в 16×16; он не является уменьшением культуры.

Росница — бирюзовая листва и крупные голубые ягоды с бликами;
бархатница — сиреневые колокольчики на изогнутых стеблях;
сердцелист — янтарные листья-сердечки на красноватых веточках;
шовник — острые серебристые листья и светлый цветок.

соседом. В таблице рядом с предметами показаны также настоящие иконки 16×16.

`exports/` содержит рабочие листы, восемь отдельных предметов и по шесть
рисунков стадий 16×32 каждого растения. Порядок видов: росница, бархатница,
сердцелист, шовник. Предметы: урожай 0–3, семена 4–7.

Культуры сохраняют прежний формат Crop.getSourceRect: две культуры на строку,
по восемь ячеек. Порядок: посев, посев, росток, молодое растение, бутоны,
зрелое, зрелое, после сбора. Нижний пиксель — y=30; поля не дают рисункам
попасть в соседнюю ячейку. Раскладка и индексы игровых данных не менялись.

Из папки CP-пака:

```powershell
python scripts/native_herbal_garden.py --install
python scripts/validate_herbal_garden.py
python scripts/validate_native_icons.py
```

Старый вызов `python art/herbal-garden/export_assets.py --install` также
собирает новые нативные рисунки. Общий генератор `draw_native_icons.py`
импортирует те же функции предметов, поэтому пересборка не возвращает старый
вариант. `--install` обновляет только рабочий каталог, без папки игры.

`native-v4/report.json` содержит размеры, цвета, хеши и раскладку кадров;
`native-v4/style-reference.png` — присланный пользователем пример.
`native-v4/before/` и `native-v3/before/` сохраняют предыдущие нативные версии,
`native-v2/before/` — первоначальные заменённые PNG и исходники. Исходные большие
рисунки 20–21 октября, промпты и прежний экспортёр остаются архивными;
при сборке они не читаются. Механики сада описаны в `../../docs/herbal-garden.md`.

Проверены размеры, прозрачность, тёмные контуры, игровые координаты всех фаз,
повторный сбор, одинаковые рабочие копии и существующая цепочка поручений.
В запущенной игре новая графика ещё не проверялась.
