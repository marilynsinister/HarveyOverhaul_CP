# Аптекарский сад: крупные рисунки → игровые спрайты

Текущая версия — `painted-v11`, 30 октября 2026.

Листья, цветы и плоды увеличены; у молодых растений и на стадии бутонов
теперь широкие цельные листья. Вокруг всех форм проходит сплошной тёмный
контур толщиной в один игровой пиксель. Зелёная листва обведена тёмным
лесным цветом, ягоды — синим, колокольчики — сливовым, золотые листья —
коричневым, белые цветы — тёплым тёмным цветом.

![Было и стало](painted-v11/comparison.png)

- Четыре новых прозрачных листа от встроенного imagegen — `painted-v11/sources/`.
  Два столбца и четыре строки: посев, росток, молодое, бутоны, зрелое,
  после сбора, урожай, пакет семян. Промпты — `painted-v11/prompts.json`.
- Отдельные высокие зрелые растения — `painted-v11/mature-portraits/`;
  промпты — `painted-v11/mature-prompts.json`.
- 32 отдельных крупных рисунка — `painted-v11/isolated/`.
- Уменьшенные тела до обводки — `painted-v11/reduced-before-outline/`.
- Сборщик — `../../scripts/painted_herbal_garden.py`; цвет, резкость и контур —
  `../../scripts/refine_herbal_pixels.py`. Пересборка использует сохранённые PNG.

Сначала создаются крупные исходники с широкими листьями и крупными частями
урожая. Зрелые растения уменьшаются пропорционально, сохраняя круглые ягоды. Молодые,
бутоны и стадии после сбора заполняют отведённую высоту кадра, чтобы широкая
листва сохраняла разнесённые ярусы. Цвет берётся из промежуточного
изображения тройного размера ближайшим соседом. Резкость использует только
непрозрачных соседей. После уменьшения добавляется тёмная обводка по восьми
соседям. Под неё заранее оставлено место: тело зрелого растения до 12×26,
с контуром до 14×28 внутри ячейки 16×32. Обводка не обрезается краями ячейки.

Прежнее осветление контура убрано согласно новой просьбе о тёмных границах.
Палитра тела — до 48 цветов, обводки — семь цветов материала; суммарно
не более 64 непрозрачных цветов. Альфа игровых PNG только 0/255. Независимые
проверки требуют яркость края 16–80/255, проверяют размеры и прозрачные поля.

[Исходники и результат](painted-v11/reduction-preview.png) · [Все стадии](painted-v11/preview.png) · [Два грунта](painted-v11/garden-preview.png) · [На цвете почвы со скриншота](painted-v11/visibility-preview.png).
Превью увеличивают готовые PNG ближайшим соседом. Последнее использует цвет
почвы из `painted-v11/reference-in-game.png`; освещение игры не моделируется.

| Лист | Рабочий путь | Размер |
| --- | --- | --- |
| herbalItems.png | assets/Items/herbalItems.png | 128×16 |
| herbalCrops.png | assets/Crops/herbalCrops.png | 256×64 |

`exports/` содержит рабочие листы, восемь отдельных предметов и по шесть
стадий каждого растения. Порядок видов: росница, бархатница, сердцелист,
шовник. Предметы: урожай 0–3, семена 4–7. Золотые сердца сердцелиста — листья;
цветы и плоды у него не добавлены.

Формат Crop.getSourceRect: две культуры на строку, по восемь кадров 16×32.
Порядок: посев, посев, росток, молодое, бутоны, зрелое, зрелое, после сбора.
Нижний пиксель y=30, прозрачное поле отделяет соседние ячейки.

Из папки CP-пака:

```powershell
python scripts/painted_herbal_garden.py --install
python scripts/validate_herbal_garden.py
python scripts/validate_native_icons.py
python scripts/check_all.py
```

Совместимые точки входа `scripts/native_herbal_garden.py` и
`art/herbal-garden/export_assets.py` вызывают текущий сборщик. Общий
`draw_native_icons.py` использует эти же иконки. `--install` обновляет
рабочий каталог мода, без изменения установленной игры.

`painted-v11/report.json` содержит размеры, цвета, хеши и раскладку;
`painted-v11/validation.txt` — проверки. Предыдущие PNG, сборщики,
проверки и документы сохранены в `painted-v11/before/`. Предыдущие рисунки
и превью остаются в `painted-v10` и более ранних папках.
В запущенной игре новый вариант не проверялся. Механики сада описаны
в `../../docs/herbal-garden.md`.
