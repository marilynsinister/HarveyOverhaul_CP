# Ассеты аптекарского сада

**Обновление 26 октября 2026:** все восемь иконок урожая и семян заменены
нативными 16×16 из [native-16](../native-16/README.md). Экспортёр сохраняет эти
иконки без обработки; описанный ниже экспорт стадий роста остаётся прежним.

Оригинальные рисунки: встроенный `image_gen`, 20–21 октября 2026 года.
Промпты — `prompts.json`, исходные прозрачные PNG — `generated/`.
Полное описание механик и открытия контента — `../../docs/herbal-garden.md`.

`preview.png` показывает именно игровые изображения, увеличенные без
сглаживания. Это полезнее для оценки читаемости, чем большие исходники.

`exports/` содержит восемь отдельных иконок 16×16, по восемь исходных кадров
16×32 для каждого растения и два листа, скопированные в рабочие пути:

| Лист | Рабочий путь | Размер |
| --- | --- | --- |
| herbalItems.png | assets/Items/herbalItems.png | 128×16 |
| herbalCrops.png | assets/Crops/herbalCrops.png | 256×64 |

Порядок видов: росница, бархатница, сердцелист, шовник. В листе предметов сначала
четыре вида урожая, затем четыре вида семян. `SpriteIndex` культур 0–3.

`export_assets.py` выполняет только техническую подготовку рисунков: выделяет
отдельные силуэты с учётом свободной раскладки генератора, уменьшает ближайшим
соседом, приводит к общей палитре из 64 цветов и бинарной прозрачности,
затем упаковывает игровые листы. Кодом растения не рисуются. Потребуется Pillow.

```powershell
python art/herbal-garden/export_assets.py --install
python scripts/validate_herbal_garden.py
```

Культуры упакованы в реальный формат Stardew 1.6: две культуры на строку,
каждой отведены восемь кадров 16×32. Порядок игровых кадров:
`посев, посев, росток, молодое, бутоны, зрелое, зрелое, после сбора`.
Формат проверен по `Crop.getSourceRect` установленной игры; обычная сетка
«одно растение на строку» здесь дала бы неправильные спрайты.

Старые рабочие PNG не заменялись. Проверки всего пака прошли;
`validation-full-pack.txt` содержит результат. В игре набор ещё не проверялся.
