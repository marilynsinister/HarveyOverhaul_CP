# Аренд: источники спрайтов и циклов

`sprites.webp` — исходный увеличенный рисунок. Нативные правки в
`sprite_fixes.png` накладываются после уменьшения и общей палитры, поэтому
пересборка не сдвигает закреплённые пиксели. Размер правок — 64×640:
четыре столбца, двадцать рядов для игровых рядов 0, 2, 4–21.
Игровой лист — 64×704: 88 кадров размером 16×32.

Обувь закреплена внутри каждого действия. Чтение использует предпочтительную
позу v4 с большой книгой (`reading_base.png`), меняется только страница
в области x=4..10, y=15..17. Исходные обложка, руки, корпус и голова сохранены.
Дыхание двигает внутренние складки пиджака: голова, шея, воротник, кисти
и внешний контур не меняются. Подвижные рукава имеют ширину 4 px с
заполненным локтевым стыком и внутренней тканью 2 px. Мебель неподвижна
при посадке, отдыхе и подъёме. В ходьбе просвет
между ногами заполнен тёмным контуром; опорная нога и поднятая на два пикселя
нога продолжают чередоваться; голова и плечи поднимаются на один пиксель
в фазах шага. Ноги зеркальны относительно оси корпуса x=7. Нейтральные
ступни одинаковы по форме и цвету. Кресло используется только дома.

`pose_bases.png` — нативные основания для поз 28–55 до исправления циклов;
`walk_bases.png` — неподвижные основания ходьбы вниз/вверх;
`gesture_bases.png` — исходные нейтральные позы для жестов и книги;
`reading_base.png` — выбранная автором большая книга и фигура из v4, кадр 28;
`native_body.py` — симметричные ноги и вертикальное движение корпуса;
`pose_layers.py` — цельные рукава, страница за исходной обложкой, дыхание;
`compose_pose_cycles.py` — слои страницы, дыхания, рук и мебели;
`cup.png` — одна и та же чашка 7×5 для всех стадий движения. Её цвета взяты
из референса, сделанного встроенным ImageGen. Головы, одежда, ноги и кресло
взяты из исходных игровых пикселей. Ноги перерисованы на нативной сетке.

Пересборка нативных слоёв и игровых PNG:

```text
python art/arend/compose_pose_cycles.py
python scripts/build_arend_sprites.py --sprites-only
python scripts/validate_arend_behaviour.py
python scripts/render_arend_animations.py
```

Пять последовательностей игры находятся в `scripts/build_arend.py` и
`assets/Code/arend.json`: чтение 28–31 + 56–59, кресло 40–43 + 64–67,
чай 44–47 + 60–63, птицы 68–71, размышление 32–35 + 72–75.

Галерея: `output/ArendSprites-2026-10-27/animations-v6-<hash>/index.html`
в общей папке модов. Новый путь зависит от PNG и анимаций, чтобы браузер
не показывал старую сборку из кеша. В ней 15 полных действий и 5 анимаций
расписания с входом, двумя повторами и выходом; слева v5, справа v6.
Дополнительные соседние ячейки не зацикливаются отдельно: их фазы включены
в соответствующие полные движения. Все 88 ячеек охвачены.
